# RedePlay

A simple institutional website developed for the Play network using HTML, CSS, and JavaScript.

## About

Play is a simple web project designed to present the network, its activities, and relevant information through a clean and accessible interface.

The project focuses on fundamental front-end development concepts, responsive layouts, navigation, and interactive elements.

## Features

* Institutional website layout
* Responsive design
* Navigation between sections
* Interactive elements
* Mobile-friendly interface

## Technologies

* HTML5
* CSS3
* JavaScript

## Purpose

This project was developed as a practical front-end project to create a simple, functional, and responsive website for the Play.
